Fonts on witbound.co.uk, served from this site only.

witbound-display.woff
  IM FELL English Roman (Igino Marini), subset to Basic Latin and a few marks and renamed
  "Witbound Display", as the OFL's Reserved Font Name requires for a modified copy. It sets the
  wordmark, the headings and the running heads. Licence: OFL-IMFellEnglish.txt

imfell-wordmark.woff
  The same face cut to the letters of "Witbound" ("Witbound Wordmark"), from the 12 Oct 2026 site.
  No page asks for it now; it stays for anything that still links it. Licence: OFL-IMFellEnglish.txt

literata-regular.woff2, literata-italic.woff2
  Literata 3.103 (Regular, Italic), subset to Latin. Body text where Georgia is missing.
  Licence: OFL-Literata.txt

atkinson-regular.woff2, atkinson-bold.woff2, atkinson-italic.woff2
  Atkinson Hyperlegible 1.006 (Regular, Bold, Italic), subset to Latin.
  Modified: the zero is drawn without its slash, for running text.
  No page asks for them now (the 12 Oct home page set its font specimen in them); they stay for
  anything that still links them. Licence: OFL-AtkinsonHyperlegible.txt
